# AI Fashion Campaign Brief — Claude Skill

Turns a client brief or product link into a production-ready AI fashion/beauty
campaign package: concept, AI model consistency spec, shot list, generation
prompts (image + video), platform cutdowns, pricing table, and EU AI Act
Art. 50 labeling.

## Install
Claude Code: drop the folder into `~/.claude/skills/` or
`claude skills install ai-fashion-campaign-brief.skill`

## Usage
"Create an AI campaign for [product link]" — the skill produces a complete,
quotable campaign package.
