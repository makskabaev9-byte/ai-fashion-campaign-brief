AI Fashion Campaign Brief — Claude Skill

Turns a client brief or a product link into a production-ready AI fashion, beauty or product campaign package: creative concept, AI model consistency spec, shot list, image and video generation prompts, platform cutdowns, a pricing table and AI-content labeling notes.

Made by Aleksandra Kabaeva, AI Creative Director · kabaeva.co

Example

Input

Luxury skincare brand. Three products. Campaign for Instagram.

Output (one package, under 3 pages)

Creative concept — one line a stranger could retell, plus why it fits the brand
Aesthetic direction — primary and fallback, with lighting and lens vocabulary
AI model consistency spec — identity anchors, skin and hair, wardrobe logic, do-not-change list
Shot list — Hook → World → Product → Proof, with timing, framing, motion and on-screen text
Generation prompts — one image and one video prompt per key shot, model-agnostic
Formats and cutdowns — 9:16, 4:5 and 1:1 deliverables mapped to Reels, TikTok, paid and e-commerce
Pricing table — a ready ladder you adjust to your own rate card
Labeling and disclaimers — AI-content label, client handoff note, "independent concept" line for spec work

See assets/campaign-brief-template.md for the exact structure.

Install

Claude Code

Copy this folder to ~/.claude/skills/ai-fashion-campaign-brief/ (or to .claude/skills/ai-fashion-campaign-brief/ inside a project, for that project only).
Check that SKILL.md sits directly inside that folder.
Start a new Claude Code session and ask: "What skills are available?" — ai-fashion-campaign-brief should be listed.
bash
git clone https://github.com/makskabaev9-byte/ai-fashion-campaign-brief ~/.claude/skills/ai-fashion-campaign-brief

Claude apps (claude.ai, desktop)

Download this repository as a ZIP (Code → Download ZIP) and upload it in the Skills section of your Claude settings. Skills must be enabled for your account.
